## 无职转生Ⅲ

{% label '热度 14万' blue %} {% label '评分 84' green %}

绝对是本季度王炸，评分84热度14万+，这个成绩确实少见。我觉得这部番的制作水平在业界都算顶尖，每一帧都在砸钱。鲁迪乌斯这次的冒险更成熟更热血，看完只想拉朋友一起入坑。

> 一句话：制作顶尖、每帧砸钱，本季王炸，拉朋友一起入坑。
## BLEACH千年血战篇-祸进谭-

{% label '评分 88' green %}

评分88，本季最高分！死神粉狂喜。友哈巴赫登场那段把紧张感拉满，灭却师和死神最终决战的压迫感做得很足。说实话，能熬到今天的都是真爱，这波值得。

> 一句话：死神粉狂喜，88 分本季最高，决战压迫感拉满。
## 幼女战记Ⅱ

{% label '热度 8万' blue %} {% label '评分 81' green %}

评分81热度8万+，谭雅又回来了。科学魔法大战打到这种程度，我每次看都忍不住感叹制作组是多舍得砸经费。

重点安利一下这两部！

> 一句话：科学魔法大战，经费舍得砸，硬核混搭必追。
## 「乙女怪獣キャラメリゼ」——焦糖味女友！

{% label '热度 3.5万' blue %} {% label '评分 75' green %}

女主一激动就变哥斯拉，这个设定我直接笑喷。黑石黒江只想过普通高中生活，但情绪一上头"嘭"地变怪兽，这反差萌谁顶得住啊！评分75，热度35075，属于那种看似日常其实超有料的番。弹幕经常刷"姐姐变小怪兽我直接融化"、"这比谈恋爱还有意思"，氛围很欢乐。

> 一句话：女主一激动变哥斯拉，反差萌欢乐番。
## 「ヤニねこ」——ニコニコ喵喵！

{% label '热度 6万' blue %} {% label '评分 67' green %}

烟熏猫娘的日常喜剧，评分67热度6万+。这猫娘烟瘾大到公寓里全是烟味，每次想戒烟都失败，看得我好心疼又好笑。弹幕热词"喵~" "烟瘾犯了" "求治愈" 刷屏。虽然评分不高，但作为放松番完全合格，我个人的看法是：适合累了的时候下饭。

另外还有两部跟烟有关的有意思：

> 一句话：烟熏猫娘日常喜剧，累了下饭刚刚好。
## 「スーパーの裏でヤニ吸うふたり」

{% label '热度 10万' blue %} {% label '评分 82' green %}

评分82热度10万+，打工人佐佐木和超市山田小姐在超市后巷抽烟的故事。表面看是爱情喜剧，但职场压抑+都市孤独感让人挺共鸣的，82分不是白得的。

> 一句话：社畜×超市店员，丧但治愈，日常系天花板。
## 「きみが死ぬまで恋をしたい」

{% label '评分 74' green %}

评分74，孤儿院培养少女杀手，但她们想谈一场直到死去的恋爱……这设定本身就够带感的，黑暗又甜蜜，喜欢暗黑向的别错过。

总之这季度好番扎堆，BL 完结篇、无职三、幼女二都是质量在线的。焦糖味女友和ニコニコ喵喵适合周末放松，想看燃的就追死神和无职。个人建议先肝无职三，看完记得来评论区跟我聊聊！

> 一句话：孤儿院杀手想谈恋爱，暗黑又甜蜜，别错过。
