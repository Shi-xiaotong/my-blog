## 薬屋のひとりごと 第3期
{% label '热度 10.8万' blue %} {% label '评分 85' green %}

猫猫在平民区恢复药师日常，一次突发事件再次把她卷入宫廷风波。剧情回归推理主线，节奏稳、细节密，马渕实作的原作底子让第三季后半段没有掉链子。

> 猫猫的毒理侦探日常，第三季继续在线。

## サイバーパンク: エッジランナーズ2
{% label '热度 11.4万' blue %} {% label '评分 83' green %}

Night City 回来了。Weak 失去所有chrome后重新面对这座城市，边缘行者们的命运在第二季继续纠缠。剧情比第一季更冷峻，动作场面保留原版风格但不再靠视觉奇观撑场。

> 夜之城的暗面，Weak 在无 chrome 状态下重新开局。

## ブラッククローバー 第2期
{% label '热度 10.3万' blue %} {% label '评分 87' green %}

斯佩德王国篇开启，阿斯塔率领魔法骑士团突袭敌方据点营救队长。评分全季最高，战斗作画和节奏把控比前期更成熟，但集数标注为0，暂未开播。

> 阿斯塔突袭斯佩德，评分87全季领跑，但还在等开播。

## テムパル～アイテムの力～
{% label '热度 5.4万' blue %} {% label '评分 76' green %}

倒霉玩家 Grid 在 VR 游戏《Satisfy》里捡到神器，获得传奇职业"Pagma 的继承者"。典型的异世界升级流开局，动作和喜剧元素搭配合理，12集完结篇幅紧凑。

> 运气差的玩家捡了神器，标准龙傲天开局，制作扎实。

## ホタルの嫁入り
{% label '热度 4.9万' blue %} {% label '评分 75' green %}

贵族千金 Satoko 外表光鲜，实则身患绝症、时日无多。剧情走浪漫悲剧路线，情感铺陈克制，适合喜欢慢节奏爱情故事的观众。

> 贵族千金的倒计时婚姻，走的是克制煽情的路线。

## 生徒会にも穴はある！
{% label '热度 4.7万' blue %} {% label '评分 73' green %}

郊外名校 Fujinasu 的学园故事，一年级生 Ume Mizunoe 国文成绩优异却卷入学生会的麻烦。喜剧加轻微福利元素，定位清晰，不追求深度。

> 优等生的校园喜剧，定位明确，轻度向。

## ジョジョの奇妙な冒険 SBR 2nd&3rd STAGE
{% label '热度 4.8万' blue %} {% label '评分 86' green %}

Part 7 沙漠竞速篇继续，Johnny 和 Gyro 穿越约750英里荒漠，"恶魔之掌"区域威胁升级。荒木飞吕彦的原作骨架过硬，动画化后动作设计保持水准。

> 沙漠竞逐进入危险区域，原作底子扎实，动作戏在线。

## 転生貴族、鑑定スキルで成り上がる 第3期
{% label '热度 2.9万' blue %} {% label '评分 69' green %}

第三季后制作公司由 MOTHER 更换为 GeyeG Pictures，9月4日宣布。评分和热度都不高，换制作方的变动可能影响观感。

> 换制作公司，评分69，观望性质更强。

## 目覚めたら最強装備と宇宙船持ち
{% label '热度 2.8万' blue %} {% label '评分 69' green %}

上班族 Sato Takahiro 醒来发现自己在一艘形似童年游戏的宇宙飞船里，装备齐全，打算以佣兵身份过上自由生活。机甲、科幻、恋爱多重标签堆叠，但执行上较为平铺直叙。

> 标签很满，执行一般，13集篇幅偏短。

## アオアシ 第2期
{% label '热度 2.6万' blue %} {% label '评分 80' green %}

碧井踏进 A 队后迅速被现实击倒，小栗林和渚的压迫感让他意识到职业足球的残酷。体育番的硬核质感稳定，24集体量比第一季更从容。

> 青春足球的残酷一面，第二季节奏更稳。

## 貸した魔力は【リボ払い】で強制徴収
{% label '评分 61' orange %}

魔幻世界观下的 RPG 设定，魔力被量化为可借贷的资源。评分全季最低，剧情和制作都没有明显亮点。

> 概念有意思，执行没跟上。

## 弱気MAX令嬢なのに、辣腕婚約者様の賭けに乗ってしまった
{% label '热度 1.3万' blue %} {% label '评分 67' orange %}

穿越成反派千金的女主高烧后记起前世记忆，与强势未婚夫的博弈展开。热度偏低，定位轻小说改编的常规作品。

> 穿越女配的日常，存在感不突出。
