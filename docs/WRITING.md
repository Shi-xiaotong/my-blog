# 写作模板与富标签速查（手写稿）

博客内容分两类，排版来源不同：

- **自动稿**（动漫 / 技术周报）：由 `_scripts/generators/` 的 prompt 直接生成，排版写死在 prompt 里（导读卡、表格、label 胶囊、`> 一句话`、`<!-- more -->` 位置），**不要**用手动模板改它们。
- **手写稿**（生活 / 游戏 / 历史 / 科学 / 推荐 / 部分技术）：用下面的 scaffold 起步，只填内容、不操心排版。

## 怎么新建一篇

```bash
hexo new post   "标题"   # 通用默认（没有更贴合的类型时用）
hexo new review "书名/片名/游戏名"   # 书 / 影 / 游评
hexo new essay  "主题"   # 历史 / 科普 / 随笔
```

`hexo new` 会按 `scaffolds/<layout>.md` 生成带好 front-matter + 结构骨架的草稿，标题、日期自动填。

> 类型映射：书评 / 影评 / 游戏评 → `review`；历史人物 / 科普 / 观点随笔 → `essay`；教程 / 工具 / 杂谈 → `post`。

## 必做（漏了会出问题）

1. **`categories` / `tags` 至少填一个**，否则不进分类页。
2. **`<!-- more -->` 必须存在**，放在导语段之后、第一个 `## ` 之前 —— 没有它首页卡片会把整篇长文摊开。
3. **长文用 `##` 分节**：目录（TOC）只认 `##` 小标题；用独占一行的 `**加粗**` 冒充小标题会导致目录为空、标题装饰出不来（生成器兜底会把它们提升成 `##`，但手写稿没有兜底）。
4. **第一人称 + 至少一句主观表达**（「说实话 / 我觉得 / 好家伙 / 个人看法」），这是博客语气要求。

## 禁忌

- ❌ **文末别用独占一行的 `---` 当分割 / 签名**：Butterfly 的 `hr_icon` 会把每个 `---` 渲染成剪刀虚线。结尾签名直接写成普通段落或收进 `{% note %}` 即可。
- ❌ 别用 `**加粗**` 独占一行冒充小标题。
- ❌ 禁用词（AI 腔，手写也要避开）：聚焦于、旨在、折射出、上述动态、与此同时、值得关注的是、引发了广泛讨论、综上所述、值得一提的是、不可忽视的是、标志着、进一步加剧了、后续进展值得持续跟踪。
- ❌ 正文里别出现 AI 思考痕迹（`*Topic 1:*`、`Wait, constraint N says...` 等）。

## 富标签速查（Butterfly）

> 参数细节以 Butterfly 官方文档为准；下面是最常用、已在站点验证过的写法。

### 导读卡 note

```markdown
{% note green %}一句话总览：……{% endnote %}
{% note blue %}……{% endnote %}
{% note orange %}……{% endnote %}
```
颜色可选：`green` / `blue` / `orange` / `red` / `purple` / `cyan`。建议开头用 `note` 放一句话结论。

### 数据胶囊 label

```markdown
{% label '热度 10.4万' blue %} {% label '评分 85' green %} {% label '类型 小说' orange %}
```
颜色同上。适合给作品 / 工具贴关键元数据（评分、平台、难度）。

### 引用块 blockquote（一句话收尾）

```markdown
> 一句话：这句是这节 / 全文的核心收尾，一句点透。
```
动漫稿每部作品、评测稿每段点评都用它收尾。

### 折叠 hide（剧透 / 长附录）

```markdown
{% hide 点开看剧透 %}
关键情节……
{% endhide %}
```

### 时间线 timeline（经历 / 版本迭代）

```markdown
{% timeline 2026-07 %}
做了什么……
{% endtimeline %}
```

### 选项卡 tabs（多方案对比）

```markdown
{% tabs 方案A, 方案B %}
<!-- tab 方案A -->
内容……
<!-- endtab -->
<!-- tab 方案B -->
内容……
<!-- endtab %}
{% endtabs %}
```

## 一个最小可发布骨架

```markdown
---
title: 标题（15~25 字，有钩子）
date: 2026-11-02 12:00:00
categories:
  - 历史
tags:
  - 人物
---

{% note blue %}一句话总览。{% endnote %}

> 一句话：……

<!-- more -->

## 背景

……

## 核心脉络

……

## 小结

> 一句话：收尾。
```
